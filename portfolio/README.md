# Personal Cybersecurity Portfolio

A standalone personal portfolio website for Sai Jayanth, using a cinematic black-and-red visual direction.

## Preview locally

Open `index.html` in a browser. The website is plain HTML, CSS and JavaScript; no build step is required.

## Files

- `index.html` — portfolio content and sections
- `style.css` — responsive black-and-red design
- `script.js` — mobile navigation and active-section state
- `hero.svg` — original decorative hero illustration

## Sections

Home, About, Expertise, Projects, Experience and Contact.

## Notes

This portfolio is added in its own `portfolio/` directory on the `personal-portfolio-red-black` branch. The original roadmap documentation on `main` is not modified.

Review all personal details and links before publishing.
